# 1.3.2-zs.1

## 中文

基于书童 Pagekin 1.3.2 的一键接入版。

- AI 服务改为在网站「我的应用」点「一键接入」后自动接入，不用自己填服务商、地址和密钥，费用从网站余额扣除。
- 知识库按字词检索，不需要配置检索模型。
- 新版本在网站发布，应用里检查更新后去网站下载。

## English

A one-click connection build based on Pagekin 1.3.2.

- AI is connected from "My apps" on the website with one click. No provider, address or key to fill in; usage is billed to your website balance.
- The knowledge base searches by words, with no retrieval model to set up.
- New versions are published on the website. Check for updates in the app, then download from the website.
